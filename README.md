# Mansão da Máfia

Projeto de jogo em Godot baseado no planejamento estratégico, tático e operacional dos documentos do projeto.

Resumo do conceito:

- Título: Mansão da Máfia — Em Busca do Livro de Contas
- Gênero: stealth / exploração / puzzle / ação
- Estrutura: 4 andares e 15 ambientes
- Objetivo: invadir a mansão, coletar chaves, resolver enigmas, abrir o cofre e fugir com o Livro de Contas
- Sistema principal: guardas, portas e chaves, passagens secretas, alerta geral e final de escape

Estrutura principal do repositório:

- DOCS PROJETO/ — documentação do projeto e planejamentos
- GODOT/ — estrutura base do projeto Godot para desenvolvimento
