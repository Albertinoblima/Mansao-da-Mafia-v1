# Estrutura base do projeto Godot

Esta pasta foi organizada conforme a documentação do projeto, com a estrutura recomendada para o desenvolvimento em Godot 4.x.

Principais pilares:

- Cenas: ambientes, personagens, interface e objetos do jogo
- Recursos: artes, armas, inimigos, itens e sons
- Scripts: lógica do jogo, estado global, guardas, enigmas e UI
- Exportar: build e exportação para web

Mapa principal previsto:

- 4 andares
- 15 ambientes
- 15 guardas
- 5 entradas
- 7 passagens secretas
- 1 cofre e 1 livro final
